Назва проєкту: Агентство нерухомості.

Короткий опис: модель агентства нерухомості. Клієнти обирають житло за допомогою рієлторів, які, в свою чергу, проводять угоди.

Опис предметної області: система вирішує проблему підбору нерухомості. 
Користувачами системи є люди, які хочуть легко купити/продати житло 
та рієлтори, у яких буде платформа для заробітку.

Перелік учасників: Олексій Гунько, Кирило Колісниченко, Ян Бойко (всі ІПЗ-24-1).

Основні сценарії використання:
1. Клієнт обирає об'єкт нерухомості на сайті.
2. Рієлтор розміщує новий об'єкт.
3. Рієлтор проводить угоду.
4. Рієлтор знімає об'єкт із сайту.

Перелік ресурсів API:
1. Список об'єктів нерухомості.
2. Список клієнтів.
3. Список рієлторів.
4. Список угод.

Перелік реалізованих endpoints:
1. Отримання об'єктів та угод за ID.
2. Отримання об'єктів за максимальною ціною та кількістю кімнат.
3. Зміна характеристик об'єкта та угоди.
4. Створення нових об'єкта та угоди.
5. Видалення об'єкта та угоди.

Інструкція із запуску проєкту.
1. Запустити проєкт у Visual Studio за допомогою F5 або команди dotnet run.
2. Увести в адресному рядку браузера localhost:[порт]/swagger, порт взяти з терміналу.
